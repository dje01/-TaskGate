# TaskGate v2 (Android) - multi-tâches
- Crée plusieurs tâches : chronométrées (temps passé dans des apps choisies, ex. Duolingo + YouTube) ou manuelles (ex. sport, tu valides toi-même).
- Tant qu'une tâche n'est pas finie : soit tout est bloqué sauf tes apps autorisées, soit seulement les apps choisies.
- Téléphone, SMS, accueil, réglages et apps des tâches non finies restent accessibles. Remise à zéro chaque jour.
